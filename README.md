# 🚦 نظام إدارة رخص القيادة والمركبات (DVLD)

هو نظام مكتبي شامل (Desktop Application) تم تطويره باستخدام لغة C# ومنصة .NET Framework، يهدف إلى أتمتة وإدارة جميع العمليات المتعلقة بإصدار وتجديد رخص القيادة والمركبات في إدارة مرور افتراضية.

تم بناء النظام بالاعتماد على معمارية الطبقات الثلاث (3-Tier Architecture)، مما يجعله قوياً، منظماً، وسهل الصيانة والتطوير مستقبلاً.

![عرض توضيحي للنظام](https://github.com/Omartube70/DVLD/blob/master/DVLD.gif)

---

## ✅ المميزات الرئيسية (Features)

* **إدارة المستخدمين والصلاحيات:** نظام تسجيل دخول آمن مع إدارة كاملة للمستخدمين وصلاحيات كل مستخدم.
* **إدارة معلومات الأشخاص (Drivers):** إضافة، تعديل، حذف، والبحث عن معلومات الأشخاص المتقدمين للحصول على رخص.
* **إدارة طلبات الرخص:** متابعة طلبات الرخص المحلية والدولية الجديدة.
* **إدارة الاختبارات:** جدولة وإدارة نتائج الاختبارات بأنواعها الثلاثة (اختبار النظر، الاختبار النظري، الاختبار العملي).
* **إدارة الرخص:** إصدار الرخص الجديدة، تجديد الرخص المنتهية، إيقاف الرخص، وحجز المركبات.
* **واجهات سهلة الاستخدام:** تصميم يركز على تجربة المستخدم لتسهيل كافة العمليات.

---

## 🏗️ المعمارية المستخدمة (Architecture)

تم بناء المشروع بالكامل على أساس **معمارية الطبقات الثلاث (3-Tier Architecture)** لضمان فصل الاهتمامات (Separation of Concerns) وتنظيم الكود:

1.  **طبقة الواجهات (Presentation Layer - DVLD):**
    * هي طبقة واجهة المستخدم الرسومية (GUI) التي يتفاعل معها المستخدم مباشرة.
    * مسؤولة عن عرض البيانات واستقبال مدخلات المستخدم.
    * تم بناؤها باستخدام **Windows Forms**.

2.  **طبقة منطق العمل (Business Logic Layer - DVLD_Business):**
    * تحتوي على القواعد والعمليات المنطقية للنظام (Business Rules).
    * تعمل كوسيط بين طبقة الواجهات وطبقة الوصول للبيانات.
    * تقوم بمعالجة البيانات قبل إرسالها إلى قاعدة البيانات أو عرضها للمستخدم.

3.  **طبقة الوصول للبيانات (Data Access Layer - DVLD_DataAccess):**
    * مسؤولة عن كل عمليات الاتصال بقاعدة البيانات (CRUD Operations: Create, Read, Update, Delete).
    * تقوم بتنفيذ استعلامات SQL وإجراءات التخزين (Stored Procedures).
    * تم بناؤها باستخدام **ADO.NET**.

## 🚀 كيفية التشغيل (Getting Started)

لتشغيل المشروع على جهازك المحلي، اتبع الخطوات التالية:

### المتطلبات الأساسية

* **Visual Studio 2019** أو أحدث.
* **Microsoft SQL Server Management Studio (SSMS)**.

### خطوات التثبيت

1.  **نسخ المستودع (Clone):**
    ```bash
    git clone [https://github.com/Omartube70/DVLD.git](https://github.com/Omartube70/DVLD.git)
    ```

2.  **إعداد قاعدة البيانات:**
    * افتح برنامج **SSMS**.
    * قم بإنشاء قاعدة بيانات جديدة بالاسم `DVLD`.
    * افتح ملف السكربت الموجود في المشروع `Database/DVLD_Database.sql`.
    * انسخ محتوى السكربت وقم بتنفيذه داخل قاعدة البيانات `DVLD` التي أنشأتها. سيقوم هذا بإنشاء جميع الجداول والإجراءات المخزنة اللازمة.

3.  **تعديل سلسلة الاتصال (Connection String):**
    * افتح المشروع باستخدام ملف `DVLD.sln`.
    * اذهب إلى مشروع طبقة الوصول للبيانات **`DVLD_DataAccess`**.
    * ابحث بداخله عن ملف الكلاس المسؤول عن الإعدادات (غالباً ما يكون اسمه **`clsSettings.cs`** أو اسم مشابه).
    * قم بفتح هذا الملف، وستجد بداخله متغيراً ثابتاً (`static string`) يحتوي على سلسلة الاتصال. قم بتعديل قيمته لتطابق إعدادات خادم SQL Server المحلي الخاص بك.

      ```csharp
      // مثال للكود الذي ستبحث عنه داخل الكلاس
      public class clsSettings
      {
          public static string ConnectionString = "server=YOUR_SERVER_NAME;database=DVLD;integrated security=true";
      }
      ```
    * استبدل `YOUR_SERVER_NAME` باسم الخادم الخاص بك (مثلاً `.` أو `localhost`).
    * قم بحفظ الملف.

4.  **بناء وتشغيل المشروع:**
    * من داخل Visual Studio، قم بعمل `Build Solution`.
    * اضغط على `Start` أو `F5` لتشغيل المشروع.
    * **بيانات تسجيل الدخول الافتراضية:**
        * **اسم المستخدم:** Admin
        * **كلمة المرور:** 1234
